# odin-recipes
Recipe page project

This is a small project where i built a basic recipes website, indexing small subpages 
in many links for each of the recipes. No CSS, only the main structure created in HTML.

Some of the skills used here were lists (ordered and unordered), indexation with internal links. links to internal project images and of course, many basic HTML tags needed for every project. Was super fun to use them in this practice!
